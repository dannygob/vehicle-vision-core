# Vehicle Vision Core

Vehicle Vision Core is the foundational repository for building an advanced computer vision system focused on vehicle analysis. The first phase of the project aims to classify vehicles based on their **body type** (sedan, hatchback, SUV, pickup, etc.). The repository is designed to grow into more complex tasks such as detection, segmentation, structural analysis, and additional vehicle‑related vision capabilities.

## Project Goals

- Build a **hybrid dataset** by merging multiple public sources.
- Classify vehicles by **physical body type** with high accuracy.
- Train and optimize a model for **TensorFlow Lite** deployment.
- Maintain a modular structure that supports future expansion.
